# Deep Learning Lab & Viva

A standalone HTML learning app for deep-learning experiments and viva MCQ practice.

## Features
- White-first editorial interface with restrained red accents
- Dark, syntax-highlighted Python code display
- Interactive deep-learning experiments and result visualizations
- Viva MCQ practice with score and streak tracking
- Preserves scroll position when moving to the next MCQ
- Responsive layout and a “Made by Ananth” credit

## Run locally
Open `index.html` in a modern browser. No build step is required.
